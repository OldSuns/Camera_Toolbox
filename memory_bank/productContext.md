# 产品上下文
这是一个基于 Flutter 的跨平台（桌面和移动端）相机工具箱应用，名为 "OldSun相机工具箱"。

**核心目标用户:** 摄影爱好者和专业摄影师。

**核心功能:**
- **EXIF 读取:** 查看照片的详细元数据。
- **EXIF 编辑:** (待实现) 修改和保存照片的 EXIF 信息。
- **快速分割:** (功能待明确) 可能与图片处理或分享相关。
- **其他工具:** 提供一系列摄影相关的辅助工具。

**技术栈:**
- **框架:** Flutter
- **状态管理:** Provider
- **核心库:** exif_reader, image_picker, file_picker, permission_handler
