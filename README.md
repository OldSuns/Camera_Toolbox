# OldSun相机工具箱

一款专为摄影爱好者和专业摄影师打造的桌面相机工具箱，让照片管理和处理变得简单高效。支持Windows、macOS、Linux三大平台，以及Android和iOS移动端。

## 主要功能

### EXIF信息查看器
轻松查看照片的完整拍摄信息，支持各种RAW格式。

- **格式支持全面**：JPG、PNG、HEIC、WebP等常见格式，以及CR2、CR3、NEF、ARW、DNG等专业RAW格式
- **信息展示详细**：相机型号、镜头参数、快门速度、光圈值、ISO感光度、拍摄时间、GPS位置等
- **中文界面友好**：EXIF标签自动翻译成中文，一目了然
- **缩略图智能提取**：RAW文件内置缩略图快速加载，无需等待全图解析
- **一键分享**：EXIF信息一键复制到剪贴板，方便分享交流

### 本地选片助手
批量预览、筛选和导出照片的利器。

- **海量图片流畅浏览**：分页加载配合多级缓存，数千张图片也能丝滑操作
- **操作灵活多样**：全选、反选、批量选择，各种选择方式随心所欲
- **大图查看体验**：支持缩放、拖拽，F键快速选择，方向键切换图片
- **RAW文件智能关联**：自动识别同名的RAW+JPG文件组合，管理更方便
- **批量导出**：选中照片一键导出到指定文件夹

### 快速分片工具
根据JPG文件自动匹配对应的RAW文件，提高后期处理效率。

- **智能文件匹配**：自动查找相同文件名不同扩展名的RAW文件
- **冲突处理策略**：提供跳过、重命名、覆盖三种处理方式
- **批量操作支持**：一次性处理大量文件，实时显示处理进度

### 批量重命名器
多种重命名策略，让文件管理井井有条。

- **四种重命名方式**：
  - 替换：替换文件名中的指定文字
  - 追加：在文件名前后添加文字
  - 自动序号：按顺序编号重命名
  - EXIF信息：根据拍摄时间、相机型号等信息重命名
- **实时预览效果**：重命名前可预览所有文件的最终名称
- **灵活排序方式**：按文件名、修改时间等多种方式排序
- **拖拽操作支持**：直接拖拽文件到应用窗口
- **撤销功能**：支持撤销上一次重命名操作
- **同名文件处理**：智能处理重复文件名问题

### 照片边框水印
为照片添加专业风格的边框和水印信息。

- **多种布局模板**：
  - 纯白边框：简洁干净的风格
  - 黑红配色：经典专业风格
  - 背景模糊+白框：突出主体效果
- **自定义信息元素**：在四角添加相机型号、镜头参数、拍摄时间、GPS位置等信息
- **品牌Logo支持**：自动识别相机品牌并添加对应Logo，支持多种位置设置
- **样式自定义**：文字颜色、粗细、阴影效果等均可调节
- **批量处理**：一次处理多张照片，提高工作效率
- **高质量输出**：支持1-100%质量调节，满足不同需求
- **实时预览**：所见即所得的编辑体验

### 图像压缩
智能图片压缩，在保持画质的同时减小文件体积。

- **批量压缩**：一次性处理多张JPG图片
- **质量自定义**：1-100%压缩质量自由调节
- **尺寸控制**：可设置最大宽度或高度，自动等比缩放
- **输出目录灵活**：可选择保存位置，避免覆盖原文件

## 技术特性

- **跨平台支持**：基于Flutter框架，一套代码同时支持Windows、macOS、Linux桌面端，以及Android、iOS移动端
- **多线程处理**：采用Isolate技术处理耗时操作，EXIF解析、图片压缩、文件拷贝等任务在后台线程执行，确保界面始终流畅响应
- **智能缓存系统**：内存+磁盘两级缓存机制，缩略图一次生成多次使用，大幅提升浏览体验
- **响应式布局**：自动适配不同屏幕尺寸，桌面端三栏布局，移动端单栏优化
- **现代化状态管理**：Provider + ChangeNotifier架构，数据流向清晰，界面更新高效
- **完善的错误处理**：友好的错误提示，详细的日志记录，让问题排查更简单

## 界面特性

### 主题系统
- **多模式支持**：浅色主题、深色主题、跟随系统设置
- **丰富的配色方案**：蓝色、红色、绿色、橙色、紫色、粉色等多种主题色
- **实时切换**：主题切换即时生效，无需重启应用

### 响应式设计
- **桌面端布局**：三栏式专业布局，充分利用屏幕空间
- **移动端优化**：单栏紧凑布局，触控操作友好
- **自适应断点**：根据屏幕宽度自动调整界面元素

### 交互体验
- **拖拽操作**：支持文件拖拽到应用窗口，操作更直观
- **键盘快捷键**：方向键导航、F键快速选择、Ctrl+A全选等
- **实时预览**：重命名、水印等操作支持实时预览效果
- **进度显示**：批量操作时显示详细进度，状态一目了然

### 设置管理
- **缓存管理**：自动清理过期缓存，支持手动清理释放空间
- **偏好设置**：记住用户的主题选择、窗口大小等个性化配置

## 📥 下载安装

### 支持平台
- **Windows**: Windows 10/11
- **macOS**: macOS 10.14+
- **Android**: Android 5.0+ (API Level 21+)
- **iOS**: iOS 12.0+

### 下载地址
前往 [GitHub Releases](https://github.com/OldSuns/Camera_Toolbox/releases) 页面下载对应平台的最新版本安装包。

### 安装说明
1. **Windows**: 下载 `.exe` 安装包，双击运行按照向导安装
2. **macOS**: 下载 `.dmg` 文件，拖拽到 Applications 文件夹
3. **Android**: 下载 `.apk` 文件，开启未知来源安装权限后安装
4. **iOS**: 通过 App Store 搜索下载

## 使用场景

### 摄影师工作流
- **拍摄后期**：用EXIF查看器分析拍摄参数，优化拍摄技巧
- **选片整理**：本地选片助手快速筛选最佳作品，RAW文件关联管理
- **批量处理**：快速分片提取RAW文件，批量重命名规范文件名

### 摄影爱好者
- **学习成长**：查看优秀照片的EXIF信息，学习大师的拍摄设置
- **作品展示**：添加专业边框水印，提升作品展示效果
- **文件整理**：批量重命名和压缩，整理手机相册和电脑图库
